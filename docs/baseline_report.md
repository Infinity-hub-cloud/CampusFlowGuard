# CampusFlowGuard Baseline 冻结报告

## 冻结对象

- Baseline 标识：`unsw_trusted_baseline_v1`。
- 数据文件：`NF-UNSW-NB15-v2.csv`。
- 本地文件 SHA-256：`05019e3ac8d55b3f074f9f042623bbbb1af2527b8b78558c69353ccb2ccefa3f`。
- 结果范围：从原 CSV 的 2,390,275 行中固定分层抽取的 120,000 行资源限制实验池，不是全量实验，也不应表述为论文全量复现。
- 数据来源、上游许可证和发布方哈希：**待人工确认**。

## 固定实验协议

使用固定 `split_seed=20260715` 生成并保存原始 CSV 行索引，训练、验证、测试分别为 96,000、12,000、12,000 行。索引互斥，窗口只在各自集合内构造，窗口大小为 8，目标为窗口最后一行。

数值缺失值处理与标准化、类别编码器均只在 train 上拟合。validation 用于三种训练方式比较、early stopping 最优权重选择和阈值选择；test 仅在上述选择确定后作最终评估。数据无显式时间字段，因此本结果不包含时间外推结论。

主模型固定为 Record Projection、2-layer Transformer、2 heads、internal size 128、Last Token 分类头和窗口大小 8。冻结模型的三个训练 seed 为 `20260715`、`20260716`、`20260717`。

## 平衡方式选择

三个候选方式均只作用于 train，validation/test 保持自然类别分布。小试使用 validation 的固定阈值 0.5，结果如下：

| 方法 | TP | F1 | PR-AUC |
| --- | ---: | ---: | ---: |
| none | 405 | 0.8482 | 0.9143 |
| class_weight | 475 | 0.8829 | 0.8818 |
| balanced_sampling | 476 | 0.9024 | 0.8533 |

因此冻结方案为 `balanced_sampling`。方案选择过程未读取 test 指标。

## 冻结归档

`artifacts/baseline_freeze/unsw_trusted_baseline_v1/manifest.json` 保存每个归档文件的 SHA-256、大小、相对路径、固定 seed、数据指纹和结果摘要。归档包含配置、split manifest 与索引、数据指纹、比较结果、三 seed 指标、混淆矩阵、ROC/PR 曲线、最佳权重、模型摘要和训练日志；不复制原始 CSV。

后续创新实验必须复用该 split manifest，并在报告中以该冻结 baseline 为参照。任何模型结构、数据划分或训练逻辑变化都必须创建新的实验标识，不能覆盖本归档。
